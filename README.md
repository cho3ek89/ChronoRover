# ChronoRover
ChronoRover is a precise time signal generator that emulates official long-wave time broadcasts to synchronize radio-controlled watches with atomic accuracy using your phone’s speaker or headphones.

Among the currently supported signals are: DCF77 (Germany), MSF (United Kingdom), WWVB (United States), JJY (Japan), and BPC (China).

Whether you’re a watch enthusiast, collector, or simply want the most accurate time possible, ChronoRover turns your smartphone into a portable time signal transmitter.

Perfect solution for Casio and Citizen owners who live beyond the range of any official time signal transmission station!

Feature and bugfix branches should be named in the following format: _feature/ISSUE_NUMBER-ISSUE_TITLE_ (i.e. _feature/1-issue-title_, _bugfix/2-issue-title_). \
Release branches and tags should be named in the following format: _release/VERSION_ (i.e. _release/1.0.0_).
